# CS50 Projects 💻

A collection of foundational C programs and problem-solving exercises completed as part of Harvard University's **[CS50x](https://cs50.harvard.edu/x/)** curriculum.

## 📂 Project Overview

| File | Problem Set / Focus | Core C Concepts & Libraries |
| :--- | :--- | :--- |
| **[caesar.c](url?id=https://github.com/mharoon49/CS50-projects/blob/main/caesar.c)** | **Caesar** (Pset 2) | Command-line arguments (`argc`, `argv`), ASCII arithmetic, string manipulation, `ctype.h`, `stdlib.h` |
| **[cash.c](url?id=https://github.com/mharoon49/CS50-projects/blob/main/cash.c)** | **Cash** (Pset 1) | Greedy algorithms, loops, conditionals, user input validation |
| **[mario-less.c](url?id=https://github.com/mharoon49/CS50-projects/blob/main/mario-less.c)** | **Mario** (Pset 1) | Nested loops, formatting console output, half-pyramid generation |
| **[readability.c](url?id=https://github.com/mharoon49/CS50-projects/blob/main/readability.c)** | **Readability** (Pset 2) | Coleman-Liau index formula, string parsing, text analysis logic |
| **[scrabble.c](url?id=https://github.com/mharoon49/CS50-projects/blob/main/scrabble.c)** | **Scrabble** (Pset 2) | Arrays, custom scoring logic, character mapping, string evaluation |

## ⚙️ Compilation & Execution

To run any of these programs locally using the CS50 development environment or a standard GCC compiler:

```bash
# Compile the program (example for caesar)
clang caesar.c -o caesar -lcs50

# Run the program with required arguments
./caesar 13
